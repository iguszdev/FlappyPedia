Flappy Potato is an arcade game inspired by Flappy Bird, in which the player controls a potato flying between obstacles. The game is built for iOS 6. Version 2.0 is the biggest update so far: all skins were redrawn from scratch (including a proper Zombie), the shop was rebuilt, and the online Tag mode got private rooms, power-ups and many quality-of-life improvements.

Gameplay

The player taps the screen (or uses their voice) to give the potato upward momentum; otherwise the character falls due to gravity. The goal is to fly through the gaps between pairs of obstacles without colliding with them, the ground, or the edge of the screen. The player receives one point for each obstacle passed. A collision ends the game.

Since 2.0 the game gets harder as you score: the pipes move faster and the gap between them slowly narrows. When a run ends you see your score, your best result and a medal – Bronze (10 points), Silver (20), Gold (30) or Platinum (50). If the app goes to the background, the game pauses automatically.

The best score is shown as BEST on the menu screen and is kept between sessions.[1]

Online Tag mode

Online mode is a game of tag for 2–4 players. On launch choose ONLINE (Tag), enter the server address, and then an optional room code. Everyone who enters the same code plays together; an empty code joins the public room. The server address and room are remembered.

  • Rounds: a round starts a few seconds after at least two players are in the room (sooner when it is full) and lasts 60 seconds. Everyone flies through the same pipes. Players who join mid-round wait for the next one.
  • Who is “it”: one random player starts as “it” (👹, red ring). “It” tags someone by flying to about the same height as them; the tagged player becomes “it”, and the previous one is immune for 2 seconds.
  • Goal: the timer counts how long each player was “it”. The lowest time wins. Wins are counted per room until you leave.
  • Shield power-ups 🔰: they appear between the pipes. Pick one up for 3 seconds of immunity (cyan bubble).
  • Crashing: hitting a pipe or the ground does not end the round – you respawn after a moment and blink while invulnerable.
  • Warnings: when “it” gets close, the screen border pulses red, and the device vibrates when you get tagged.
  • HUD: seconds left in the centre, the current “it” top left, your own time as “it” top right, and the ping below the Menu button.
  • Skins: other players see your equipped skin and your name.

Installation from GitHub (PC / Linux / Mac)

⚠️ Important: The application can be installed using a Linux, Windows, or macOS computer. It is not possible to download and install the file directly from a browser on an iOS device.

All project files, including the latest client app FZ2,0.ipa and the server script server.js, are in the official GitHub repository (release FZ2,0).

1. Installing the game on iOS 6

  1. Download the FZ2,0.ipa file to your computer's disk.
  2. Install a sideloading program on your computer (e.g. Sideloadly, or Apple Configurator on macOS).
  3. Connect your iOS 6 iPhone / iPad / iPod to the computer with a USB cable, drag the FZ2,0.ipa file into the program, and click “Start” / “Install”. (A jailbreak and the AppSync tweak are required on older systems.)
  4. Updating from 1.x: just install 2.0 over the old version – your best score, currency and settings are kept.

2. Running your own server (local host)

  1. Download the server.js file from the GitHub repository (it must be the 2.0 version – older servers do not support rooms and shields).
  2. Make sure Node.js 8 or newer is installed on your computer. No npm install is needed.
  3. Run the server in a terminal:
    node server.js
    Or use a custom port:
    PORT=4000 node server.js
  4. The server prints your local IP addresses (for example 192.168.0.10:3000). Everybody on the same Wi-Fi network enters that address in the game, picks the same room code, and plays together.
  5. To play over the internet, forward the server’s TCP port on your router. The connection is not encrypted, so share the address only with people you trust.

3. Building from source (optional)

The source consists of ViewController.m, PotatoSkinView.h and PotatoSkinView.m (ARC, iOS 6 deployment target). Besides the default frameworks, link CFNetwork, AudioToolbox, AVFoundation and QuartzCore. The README in the repository describes the steps in detail.

Technical aspects

  • Movement is now time-based: the game measures the time between frames, so speed no longer depends on a stable 60 FPS. Online, pipes are spawned by distance from a shared random seed, so every player sees the same course.
  • Network communication uses plain TCP with one JSON message per line, which works with the aging iOS 6 networking stack (CFStream). Positions are sent about 30 times per second and smoothed on the receiving side.
  • The server (server.js, Node.js, no dependencies) keeps separate rooms and validates tags (who is “it”, immunity, whether the players are alive and close enough). Movement itself is still decided by each client, so the mode is not cheat-proof.
  • All skins are drawn with Core Graphics at run time – no image assets.
  • Sound detection (voice control) uses the AVFoundation library and analyzes the average sound power in decibels.
  • The High Score (“BEST”), the currency, the selected skin and the list of owned skins are saved in the device’s storage (NSUserDefaults).[1]
