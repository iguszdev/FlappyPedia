Flappy Potato is an arcade game inspired by Flappy Bird, in which the player controls a potato flying between obstacles. The game was built in its classic form for iOS 6. The dark Halloween Update is currently active and adds multiplayer support, with an option to run your own local host server.

Gameplay

The player taps the screen (or uses their voice) to give the potato upward momentum; otherwise the character falls due to gravity. The goal is to fly through the gaps between pairs of obstacles without colliding with them, the ground, or the edge of the screen. The player receives one point for each obstacle passed. A collision ends the game.

The best score is shown as BEST on the menu screen and is kept between sessions.[1]

Halloween Update 🎃 – What's new?

Halloween event is live! Gameplay changes apply throughout October.

For the spirit of Halloween, the game received a dark and atmospheric update:

  • Scream to Fly (voice control) 🗣️: Using the button in the menu, you can switch controls from touch to voice. Scream into the microphone to make the potato jump – the louder the sound, the higher it flies.
  • Candies and character shop 🍬: Candies appear randomly during flight. Collect them to earn currency. For 15 candies you can randomly unlock a new look for your potato.
  • Dark skins: Replace the classic base pumpkin with the Ghost (👻) or the Zombie (🧟) with a characteristic scar.
  • Spooky visual effects: The potato leaves a fading dark trail in flight. The clear sky is now purple-navy gloom, and bats, ghosts and spiderwebs (🦇, 👻, 🕸️) drift across it instead of clouds.
  • New obstacles: Pipes have a dark gray-orange color scheme.
  • Multiplayer: Players on the same network can play together on a local host server (see Installation).

Installation from GitHub (PC / Linux / Mac)

⚠️ Important: The application can be installed using a Linux, Windows, or macOS computer. It is not possible to download and install the file directly from a browser on an iOS device.

All project files, including the latest client app FZ1,4.ipa and the server script server.js, are in the official GitHub repository.

1. Installing the game on iOS 6

  1. Download the FZ1,4.ipa file to your computer's disk.
  2. Install a sideloading program on your computer (e.g. Sideloadly, or Apple Configurator on macOS).
  3. Connect your iOS 6 iPhone / iPad / iPod to the computer with a USB cable, drag the FZ1,4.ipa file into the program, and click "Start" / "Install". (A jailbreak and the AppSync tweak are required on older systems.)

2. Running your own server (local host)

  1. Download the server.js file from the GitHub repository.
  2. Make sure the Node.js environment is installed on your computer.
  3. Run the server in a terminal:
    node server.js
    Or use a custom port:
    PORT=4000 node server.js
  4. The server prints your local IP addresses (on the same Wi-Fi network). Players connect to one of them and play together in multiplayer mode.

Technical aspects

  • Movement is calculated per frame rather than per unit of time, so game speed depends on a stable 60 FPS.
  • Network communication uses TCP (one JSON message per line), which works with the aging iOS 6 networking stack (CFStream).
  • Sound detection uses the AVFoundation library and analyzes the average sound power in decibels.
  • The High Score ("BEST"), the number of candies collected, and the selected skin are saved in the device's storage (NSUserDefaults).[1]
